# 研究可信度改进清单

当前 `momentum_60d` 实验仅验证了工程链路能运行；不能作为策略有效性、历史绩效或投资结论。以下目标按优先级和依赖顺序实施；每项完成后必须通过验收，再进行后续事项。

## P0：阻断可信绩效发布的问题

### 1. 公司行为完整性门禁

- 未复权价格回测时，`corporate_action` 不能作为允许为空的最佳努力数据。
- 逐标的覆盖分红、送股、转增等已支持公司行为；将其与公告、除权除息日和账户流水对账。
- 抓取失败、覆盖不全、事实冲突或无法核验时，数据集/实验不得发布可信绩效。
- 验收：包含已知分红和送转的黄金样例中，除权前后账户总权益连续；真实实验的公司行为覆盖和异常清单可审计。

### 2. 证券主数据时点化与校验

- 使用真实的上市日期、退市日期、证券状态和板块信息，不得以统一占位日期替代。
- 校验主数据与股票池标签、行情首日/末日一致；缺失行情须能区分未上市、退市、停牌与数据缺失。
- 上市天数、因子上市期限制、涨跌停规则和回测可交易性均以该主数据为准。
- 验收：`security_master` 中每个标的的上市/退市事实可追溯；新股在真实上市满 120 个交易日之前不会进入因子候选集。

### 3. 固定信号日订单，移除执行日信息驱动的重算

- 在信号日收盘后固定订单方向和数量，并单独保存不可变的计划订单账本。
- 执行日只允许按当日开盘行情模拟成交、部分成交或拒单；不得据开盘价、停牌状态或涨跌停状态预先删单、改量或重优化。
- 将计划、提交、成交与拒绝订单以稳定 ID 关联，报告每笔差异及原因。
- 验收：改变任一执行日开盘价或可交易状态，不改变信号日生成的订单；执行结果仅在成交/拒绝账本中变化。

## P1：提升数据可靠性的门禁

### 4. 覆盖完整性与独立价格核验

- 按真实上市至退市区间、官方交易日历检查每只股票和两个基准的日线覆盖。
- 为股票日线增加独立来源的抽样/全量交叉核验；价差、缺行和字段差异须进入质量报告。
- 影响因子或成交的严重异常应阻断实验，而非仅作为报告备注。
- 验收：质量报告列出逐标的覆盖率和缺失分类；主源与校验源的差异、豁免和阻断结论均可追溯。

### 5. 数据时点与修订治理

- 记录每份原始快照的获取时间、供应商版本和内容哈希，并保存可复算的标准化版本。
- 对供应商历史修订建立差异检测；研究报告标明数据“可得时点”的边界。
- 验收：同一历史区间重拉数据时，能识别逐字段修订，并可选择复现旧版本或采用新版本。

## P2：恢复研究有效性与执行诊断

### 6. 停牌与不可成交订单策略

- 明确停牌、涨跌停和资金不足订单是取消还是延期；保持订单状态、原因和实际成交日期可审计。
- 验收：报告能区分停牌、涨跌停、资金不足及其他原因造成的未成交，并量化现金拖累。

### 7. 官方交易日历与执行偏离诊断

- 用官方交易日数据替换工作日近似日历。
- 记录每个调仓日的目标权重、计划订单、实际成交权重、未成交金额和偏离比例。
- 验收：股票与基准均覆盖每个标记为开盘的交易日；每个成本情景均可量化计划组合与实际组合差异。

### 8. 样本外研究设计与准入标准

- 用时点可得的股票池替代事后固定样本；扩大覆盖范围并记录股票池形成规则。
- 建立冻结训练、验证、隐藏样本外区间或滚动窗口；记录试验次数和实验谱系。
- 对比沪深 300、等权股票池与低换手动量基准，预先定义成本后超额收益、回撤和换手率阈值。
- 验收：报告分别展示各区间的收益、回撤、换手和成本后结果；只有同时满足预定义阈值的策略才可标记为候选。

## 发布使用边界

- P0 任一项目未完成：实验最多标记为“工程运行成功”，不得作为可信绩效、策略有效性或投资建议展示。
- P1 未完成：结果可用于接口和流程验证，但数据可靠性结论必须标记为未通过。
- P2 完成并不自动证明策略有效；仍需依照冻结的样本外评价与准入标准独立判定。

## 当前结论

现有结果存在未复权价格配合空公司行为表、证券主数据日期失真、执行日信息参与订单投影、单源股票日线及事后固定股票池等问题。它仅能说明部分工程链路可复现，不构成可信历史回测或投资建议。
