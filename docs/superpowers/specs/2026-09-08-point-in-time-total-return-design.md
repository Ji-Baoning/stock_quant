# 时点化总收益连续价格设计

## 目标

消除当前研究运行把 `daily_bar.close` 直接伪装为 `adjusted_close` 的行为。动量因子改为读取本项目基于已核验公司行为构造的、时点化总收益连续价格；下单、涨跌停判断、账户估值和公司行为记账继续只使用未复权的可交易价格。

本设计只解决“复权行情与已核验公司行为的一致性”。时点化全市场股票池、真实供应商验收、复杂公司行为支持和策略调优不在本次范围内。

## 决策与原则

1. 价格的主事实仍是 `daily_bar` 的未复权 OHLC；任何复权/总收益价格都不能覆盖它。
2. 新的连续价格由固定数据集内的 `daily_bar` 与已接受的 `corporate_action` 唯一导出，而非直接信任供应商的可能回溯修订的复权序列。
3. 连续价格不对历史价格做“事后回填”。事件只从其 `ex_date` 起影响指数；因此新发现的未来事件不能改变此前任一交易日的值。
4. 只有状态为 implemented、事实完整、受当前账户支持（现金分红、送股、转增）且 `announcement_date <= ex_date` 的事件可进入连续价格。配股、合并、换股、来源冲突、日期/比例不完整或公告晚于除权日的事件均是不可信断点。
5. 不可信断点不静默回退到未复权收盘价。跨越该断点的 60 日动量必须无效，并带有明确原因；Research 模式也不得把缺失的连续价格当作可接受输入。

## 数据模型与计算

数据发布在公司行为标准化完成后，为每个 `daily_bar` 股票交易日生成新增不可变表 `adjusted_bar`。该表至少保存：

```text
trade_date, symbol, source, adjustment,
raw_close, adjusted_close, adjustment_factor,
quality_severity, invalid_reason, applied_action_ids
```

- `source` 为未复权收盘价的权威来源；`adjustment` 固定为 `internal_total_return_v1`。
- `applied_action_ids` 是在该交易日首次计入的公司行为 ID，保证每个派息/送转可审计。
- `quality_severity` / `invalid_reason` 标明无法可靠跨越的事件，不以缺失值掩盖事实。

每只证券在首个有效未复权收盘日设 `adjusted_close = raw_close`。其后的每个交易日递推：

\[
TR_t = TR_{t-1} \times \frac{P_t \times (1 + b_t + c_t) + d_t}{P_{t-1}}
\]

其中 `P` 是未复权收盘价，`d` 是除权日现金分红/股，`b` 是送股比例，`c` 是转增比例；没有可接受事件时三者为零。公司行为在除权日首次作用，且不会改变前一日及更早的 `TR`。同日合并的多个接受事件按归一化后的唯一事件记录一次性相加/相乘。配股等未支持事件不进入公式。

若断点发生在某日，表保留该日原始价格与错误原因，但不声称其与前日连续。后续原始价格仍可保存；因子只有在其完整 61 个观测窗口不含断点时才可恢复资格。

## 研究与回测边界

`_DatasetFactorAdapter` 改为读取 `adjusted_bar`，并传递其中的 `source`、`adjustment`、`adjusted_close` 与质量状态；不再从 `daily_bar.close` 构造伪复权输入。`Momentum60` 升级为 `2.0.0`，以将旧的未复权结果与新结果永久隔离。默认实验规格相应锁定新版本。

研究冻结的数据集若没有 `adjusted_bar`，或该表不能为股票池提供所需字段，必须在因子/回测前失败；禁止回退到旧行为。旧数据集和实验仍可读取、审计和复现其旧规格，但不可被当作新可信口径重新发布。

事件驱动账户、订单计划、成交、价格限制和每日权益计算仍读取 `daily_bar` 与 `corporate_action`。这保证同一公司行为在研究信号中反映总收益、在账户中反映现金和份额变化，而不会把复权价用于假想成交。

## 管线、审计与错误处理

1. `DataPipeline` 在规范化公司行为和日线完成后构造 `adjusted_bar`，并连同其他表由 `DatasetPublisher` 内容寻址发布。
2. 构造器对每只证券按交易日和事件 ID 稳定排序；输入相同则输出字节稳定。`dataset_manifest.json` 记录该表的哈希和行数，现有 dataset version 因新增表而自然变化。
3. 不支持、冲突或不完整事件写入既有隔离/质量产物，并在 `adjusted_bar` 上留下可供因子识别的断点。公司行为覆盖证据门禁继续独立执行，不能被连续价格生成替代。
4. 实验产物和报告至少呈现 `adjustment=internal_total_return_v1`、因子版本以及连续价格的断点/无效行数量，令审阅者能区分“数据不足”与“策略表现”。
5. README、运行手册和项目记忆删除“未复权动量”的现状表述，改为说明新的数据要求和旧数据集不能用于新因子。

## 测试与验收

单元测试必须覆盖：

- 无事件时连续价格等于原始收盘价格；
- 现金分红、送股、转增及同日合并事件的精确递推；
- 同一事件只应用一次；新事件不会改写其 `ex_date` 前的连续价格；
- 未支持、冲突、不完整、公告晚于除权日的事件产生可追溯断点；
- 连续价格的来源/调整口径不会在单一证券内混用。

集成测试必须覆盖：

- 发布数据集包含 schema 正确、可读且内容寻址稳定的 `adjusted_bar`；
- 正式研究的因子输入确实来自该表，缺表时失败而非退回 `daily_bar.close`；
- 动量窗口跨断点时无效，离开断点满 61 个观测后可恢复；
- 同一冻结数据集和规格产生稳定的因子、实验 ID 与报告审计字段；
- 账户仍以未复权价格成交与估值，且公司行为账本不因新因子输入而重复记账。

验收不以收益提高为标准，而以以下事实为标准：任取一个已核验的分红或送转事件，可从 `adjusted_bar.applied_action_ids` 追到标准公司行为记录，并同时从账户流水追到同一经济事件；该事件之前的因子输入不因之后的公司行为而变化。

## 非目标与后续

本次不引入供应商复权价作为因子主源、不支持配股/合并/换股、不补建历史成分股股票池，也不进行参数搜索。完成后，下一可信性子项目是：基于真实来源的可复跑验收和留档；之后才进入时点化股票池与样本外稳定性验证。
