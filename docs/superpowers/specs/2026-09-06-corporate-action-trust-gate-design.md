# 公司行为可信度门禁设计

## 目标

将公司行为从“可选、允许空表”的辅助数据提升为未复权价格回测的可信度前置条件。系统同时支持：

- `engineering`：允许开发和链路验证继续运行，但结果不可作为可信绩效发布。
- `research`：正式研究默认模式；相关公司行为没有可审计的完整证据时，拒绝在回测前运行并发布实验。

本设计不把缺少公司行为的标的静默排出股票池，也不把空表默认解释为“没有公司行为”。

## 范围与非目标

范围包括数据更新、标准化数据集、回测前可信度检查、研究运行状态、实验评价/报告和测试契约。

本次不实现全市场股票池、完整的历史修订数据服务或新增未支持的公司行为类型。现有账户已支持的现金分红、送股和转增必须进入该门禁；不支持的权利发行等事实应成为明确的不可信原因。

## 核心模型

新增 `DataTrustMode` 枚举：

- `engineering`
- `research`

正式 `research run` 的默认值是 `research`。模式须写入冻结实验规格、运行清单、指标和报告，不能只作为命令行瞬态参数。

新增标准化表 `corporate_action_coverage`。其主键为 `dataset_version` 外的稳定数据集内容、`symbol`、`window_start`、`window_end` 和证据来源；发布后由数据集上下文与其他标准化表一起只读访问。每条记录包含：

- `symbol`、覆盖起止日；
- 抓取状态（成功、空结果、失败、未请求）；
- 每个供应商/端点的原始快照引用与内容哈希；
- 核验结论（`VERIFIED`、`UNTRUSTED`）及结构化原因；
- 生成时间和数据源版本信息。

“已核验为空”仅在所有适用来源成功响应、覆盖区间明确、且没有可用公司行为时成立。抓取异常、空响应语义不明确、缺少来源、事实不完整或来源间冲突均为 `UNTRUSTED`。

## 数据流与门禁

1. 数据更新为每个股票和请求窗口采集公司行为来源结果，保存原始响应并建立覆盖证据。
2. 标准化与对账产生事实表 `corporate_action` 和证据表 `corporate_action_coverage`；两者均进入不可变数据集版本。
3. 研究运行冻结数据集后，基于回测窗口及可能持有的标的读取覆盖证据。
4. 若任一相关标的没有 `VERIFIED` 证据：
   - `research`：在回测阶段前失败，保留运行失败清单和逐标的原因，不发布实验目录；
   - `engineering`：回测可以完成，但写入结构化不可信结论，评价不得为 `ACCEPTED`，报告不可展示为可信绩效。
5. 若证据完整：回测按已有公司行为账户逻辑入账，并将覆盖结论、证据哈希和账本摘要写入实验产物。

回测运行时还须校验：处于持仓期的公司行为有完整事实、`announcement_date` 不晚于实际可得时点、`record_date`/`ex_date` 合法，且已支持事件能映射到账户流水。违反任一条件按上述模式处理。

## 订单与结果边界

本项不改变因子或选股规则。它只定义未复权价格的收益核算边界：缺失公司行为时不能把价格变化误报为完整的总收益。

`engineering` 结果可供接口、账本和故障诊断使用，但必须同时满足：

- 运行/指标状态为 `UNTRUSTED` 或等价不可发布状态；
- 报告顶部显示醒目的不可信原因与受影响标的；
- 注册表不产生 `ACCEPTED` 实验；
- 命令行和 API 返回值可区分“运行完成”与“可信绩效已发布”。

## 错误处理与可审计性

所有不可信情形采用稳定错误码，至少区分：来源抓取失败、未请求、空结果未核验、覆盖不足、字段不完整、来源冲突和不支持的公司行为。

运行清单、质量报告和实验报告必须保留标的、日期范围、错误码、原始快照引用和证据哈希。不得仅保留人类可读错误文本。

## 测试与验收

- 黄金样例：已知现金分红、送股、转增在除权前后保持账户总权益连续，且现金/持仓流水可对账。
- 覆盖测试：成功且无事件的响应产生 `VERIFIED` 空覆盖；抓取失败、未请求、模糊空响应、覆盖不足和冲突均产生 `UNTRUSTED`。
- 模式测试：同一不可信数据集在 `engineering` 可完成但不可发布；在 `research` 回测前失败且不产生实验目录。
- 产物测试：模式、可信度结论、逐标的原因和证据哈希被写入冻结规格、运行清单和报告。
- 回归测试：现有公司行为账本、数据集不可变性、正常可信数据集的研究发布流程保持有效。

## 成功标准

在未复权价格回测中，空公司行为表不再能生成被接受的正式绩效；每个可信实验均可追溯到覆盖整个相关回测窗口的公司行为证据和账户流水。
